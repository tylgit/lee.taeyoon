# 책 만들기 (book-build)

`interview` 스킬이 모아 둔 답변을 한 권의 책으로 엮는다.
어르신은 "책으로 만들어 줘" 한마디만 하시면 된다. 나머지는 이 순서대로 진행한다.

## 지켜야 할 원칙

1. **없는 이야기를 지어내지 않는다.** 답변에 없는 사실(연도, 이름, 지명, 사건)을 새로 만들지 않는다.
   문장을 다듬고 순서를 잡고 이어 붙이는 것까지가 우리 몫이다.
2. **어르신의 말투를 살린다.** 답변이 "~습니다"면 존댓말로, "~이다"면 평서체로 쓴다.
   본인이 쓰신 좋은 문장은 그대로 살린다.
3. **답변이 적어도 책을 만든다.** 재료가 적으면 장을 줄이고, 마지막 장에
   "여기서부터 이어집니다"라고 적어 다음에 이어 쓸 수 있게 한다. 억지로 늘리지 않는다.
4. **애매한 것은 표시한다.** 받아쓰기 오류로 보이는 말, 이름의 한자, 앞뒤가 안 맞는 내용은
   추측해서 고치지 말고 작업이 끝난 뒤 어르신께 여쭐 목록으로 정리한다.

## 다섯 단계

### ① 답변 현황 확인

```
python3 tools.py status
```

몇 문항에 답하셨는지, 어느 장이 비었는지 표로 나온다.
답변이 하나도 없으면 "먼저 인터뷰부터 하시겠어요?" 하고 `interview` 스킬을 권한다.

절반도 안 채워졌으면 이렇게 여쭙는다.
"지금 있는 것만으로 1부를 먼저 만들어 볼까요, 아니면 더 이야기하고 나서 만들까요?"

### ② 책 제목·지은이·머리말 정하기 → `book/meta.md`

답변 전체를 읽고, 그 안에서 제목을 뽑는다. 어르신이 실제로 하신 말이나
반복해서 나오는 장면에서 가져오는 것이 가장 좋다.

- 좋은 예: 『영랑호 물빛』, 『펜대를 들고 살아라』, 『덤비지 마라』, 『포도나무 아래에서』
- 나쁜 예: 『나의 인생』, 『아름다운 추억』 — 누구의 책인지 알 수 없다

제목 후보를 두세 개 만들어 어르신께 고르시게 한다.

`book/meta.md` 형식:

```markdown
---
제목: 영랑호 물빛
부제: 원산에서 속초까지, 나의 뿌리와 어린 시절
지은이: 황금자
엮은이: 샬롬대학 자서전 교실
펴낸날: 2026년 8월
---

# 머리말

(어르신의 목소리로, 3~4문단. 어디서 태어나 어떻게 살았는지,
이 책에 무엇을 남기려 하는지를 담는다.)
```

### ③ 답변을 이야기로 옮겨 쓰기 → `book/chapters/`

`interview/answers/`의 문답을 **흐르는 이야기**로 다시 쓴다.
질문과 답이 그대로 남아 있으면 안 된다. 읽는 사람은 질문지를 모른다.

파일 이름은 `01.md`, `02.md` … 순서대로. 각 파일의 첫 줄은 `# 장 제목`.

표준 12장 구성(재료가 넉넉할 때):

| 장 | 제목 예시 | 재료 |
|---|---|---|
| 1 | 이름에 담긴 뜻 | 이름·아명·별명 |
| 2 | 태어나고 자란 곳 | 고향, 떠오르는 풍경 |
| 3 | 아버지 | 아버지 |
| 4 | 어머니 | 어머니 |
| 5 | 집안 어른과 형제 | 조부모, 형제자매 |
| 6 | 우리 집 살림 | 생계, 부모님 말씀 |
| 7 | 살던 집과 동네 | 집 구조, 동네 소리와 냄새 |
| 8 | 그 시절의 큰일 | 해방·6·25·피난·이사 |
| 9 | 헤어짐과 아픔 | 이별, 잊지 못할 일 |
| 10 | 밥상의 기억 | 자주 먹던 것, 특별한 음식 |
| 11 | 놀이와 동무 | 놀이, 친구 이름 |
| 12 | 나를 웃게 한 것 | 기쁨, 그리고 남기고 싶은 말 |

재료가 적으면 3~6장으로 줄인다. 억지로 12장을 채우지 않는다.

한 장을 쓰는 방법:

- 한 문단은 3~5문장. 문단 사이는 넉넉히 띄운다.
- 답변의 사실을 먼저 놓고, 그다음에 그 사실이 무슨 뜻이었는지 한두 문장 덧붙인다.
- 어르신이 인용하신 말(부모님 말씀 등)은 `> ` 인용문으로 따로 세운다.
- 장면이 바뀌면 `---` 한 줄을 넣는다. 책에서 `· · ·` 로 나온다.
- 장의 마지막 문단은 여운이 남게 맺는다.

예시:

```markdown
# 두 딸을 키우신 어머니

어머니 성함은 박금녀입니다.

아버지와 같은 해인 1921년에 원산에서 태어나셨습니다. ...

그러면서 우리에게 자주 하시던 말씀이 있었습니다.

> 공부 열심히 잘해라.
> 언니하고 싸우지 마라.

이 두 마디가 어머니의 말씀 전부였던 것 같습니다. ...
```

### ④ 조립하기

```
python3 tools.py build
```

`book/output/` 에 세 가지 파일이 만들어진다.

- `제목.docx` — 워드. 표지·머리말·차례·본문이 다 들어 있고 바로 인쇄할 수 있다
- `제목.pdf` — 그대로 보내 드리거나 인쇄소에 넘길 수 있는 파일
- `제목.html` — 웹브라우저로 여는 파일. PDF가 안 만들어졌을 때는
  이 파일을 열어 [인쇄] → [PDF로 저장] 하면 된다

글자 수와 장 수가 화면에 나온다. 그 숫자를 어르신께 알려 드린다.

### ⑤ 전달하고 저장하기

1. 만들어진 파일을 어르신께 보내 드린다.
2. 이렇게 말씀드린다.
   "○○장, 약 ○○○○자로 엮었습니다. 워드 파일은 직접 고치실 수 있습니다."
3. ①~④에서 모아 둔 **여쭐 목록**을 함께 드린다.
   "몇 가지만 확인 부탁드립니다" 하고 3~5개 안쪽으로 짧게.
4. 저장소를 쓰는 경우 커밋한다.

```
git add book/ interview/
git commit -m "자서전 원고와 완성본 추가"
```

## 어르신께 말씀드릴 때

- 전문 용어를 쓰지 않는다. "빌드"가 아니라 "책으로 엮습니다".
- 한 번에 한 가지만 여쭙는다.
- 진행 상황을 짧게 알려 드린다. "지금 3장을 쓰고 있습니다."
- 다 되면 무엇이 만들어졌는지 파일 이름으로 말씀드린다.

## 짝이 되는 스킬

- `interview` — 질문을 하나씩 여쭈어 재료를 모은다.
  `interview`가 재료를 모으고, `book-build`가 책을 만든다.
