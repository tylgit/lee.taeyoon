# 자서전 완성본 책 만들기 스킬

모은 답변(`autobiography/answers/`)을 흐르는 글로 엮어 완성본 책을 만듭니다.

## 순서

### 1. 재료 점검

- `python3 autobiography/tools.py status`로 답변 현황을 확인합니다.
- 답변이 아주 적으면(대략 20문 미만) 사용자에게 알립니다: "지금까지 답하신 것만으로도 얇은 책을 만들 수 있지만, 더 모으면 훨씬 풍성해집니다. 지금 만들까요?" — 사용자가 원하면 그대로 진행합니다.

### 2. 책 정보 확인

- `autobiography/book/meta.md`를 읽습니다. 제목/지은이가 괄호 그대로면 사용자에게 여쭙니다. (질문 90번 답 — "내 인생 책의 제목" — 이 있으면 그것을 제안합니다.)
- 머리말이 비어 있으면 답변들을 바탕으로 초안을 써서 보여 드리고, 확인받은 뒤 meta.md에 넣습니다.

### 3. 장 원고 쓰기 (책의 핵심 작업)

각 묶음(A–L)마다 `autobiography/book/chapters/01-뿌리.md` 형식으로 장 원고를 씁니다 (번호는 01–12, 파일명은 `번호-짧은제목.md`).

- 파일 첫 줄은 `## 제1장. 나의 뿌리 — 이름, 고향, 가족` 형식의 장 제목.
- 그 장에 속한 답변들("다듬은 글" 기준, 없으면 원문)을 **시간 순서에 맞게 이어지는 이야기**로 엮습니다. 질문·답 형식을 버리고 흐르는 산문으로 씁니다.
- **답변에 없는 사실은 절대 지어내지 않습니다.** 이음말("그 무렵", "몇 해가 지나")로만 연결합니다.
- 1인칭, 담담하고 따뜻한 문체. 어르신의 말투와 표현을 최대한 살립니다.
- 답변 속 [확인 필요] 표시는 그대로 남깁니다.
- 답변이 하나도 없는 묶음은 장을 만들지 않고, 어느 장을 뺐는지 나중에 보고합니다.
- 장마다 쓰고 나서 사용자에게 보여 드리고 확인받는 것이 원칙입니다. 다만 사용자가 "다 만들어 줘"라고 하면 전부 쓴 뒤 한꺼번에 검토받습니다.

### 4. 조립과 변환

- `python3 autobiography/tools.py build` 실행 → `autobiography/book/output/`에 md·html·docx·pdf가 생깁니다.
- 장 원고 없이 질문·답 모음 형식을 원하면 `build --qa`.
- PDF가 만들어지면 첫 장과 본문 한 쪽을 `pdftoppm -jpeg -r 60`으로 떠서 눈으로 확인합니다 (한글 글꼴 깨짐, 표지 모양). 한글이 깨지면 `apt-get install -y fonts-nanum` 후 다시 build.

### 5. 마무리

- 완성 파일 4종을 SendUserFile로 보내 드립니다 (쪽수와 함께).
- 교정 보고를 짧게 드립니다: 몇 문의 답이 들어갔는지, 뺀 장, [확인 필요]로 남은 곳 목록.
- chapters/와 output/을 포함해 커밋·푸시합니다 (예: `책: 완성본 1판 조립`).

## 지키는 것

- 사실 창작 금지. 미화 금지. 어르신의 목소리가 책의 주인입니다.
- 다른 가족 이야기가 많은 장은 "책에 넣기 전에 그분께 보여 드리는 것이 좋습니다"라고 한 번 안내합니다.
- 완성본을 다시 만들 때는 이전 output/을 덮어씁니다 — 판을 남기고 싶다면 커밋 이력이 판 기록입니다.
