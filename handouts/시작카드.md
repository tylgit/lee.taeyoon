# 말로 만드는 나의 자서전 — 시작 카드

*(샬롬대학 챗지피티 클래스 · 이 카드 한 장이면 됩니다)*

---

## 매일 하는 것은 세 걸음뿐입니다

1. **클로드(Claude)를 엽니다.**
2. 이렇게 말합니다: **"인터뷰 이어서 해 줘"**
3. 질문이 나오면 **마이크 단추를 누르고 말로 답합니다.**

단어 몇 개만 말씀하셔도 됩니다. 문장은 클로드가 만듭니다.

---

## 이 문장들만 알면 됩니다

| 하고 싶은 것 | 이렇게 말하세요 |
| --- | --- |
| 맨 처음 시작할 때 | **"인터뷰 시작해 줘"** |
| 매일 이어갈 때 | **"인터뷰 이어서 해 줘"** |
| 이 질문은 넘어가고 싶을 때 | **"건너뛰어 줘"** |
| 기억이 안 날 때 | **"기억이 안 나"** (그것도 답입니다) |
| 얼마나 했는지 궁금할 때 | **"지금까지 얼마나 했어?"** |
| 정리된 글을 고치고 싶을 때 | **"○○ 부분을 이렇게 고쳐 줘"** |
| 질문을 다 마쳤을 때 | **"이제 책으로 만들어 줘"** |

---

## 마이크 단추는 여기 있습니다

- **휴대폰·태블릿**: 글자판(키보드)에 있는 마이크 그림
- **컴퓨터**: 글 쓰는 칸 옆의 마이크 그림 (없으면 자판으로 쓰셔도 됩니다)

---

## 꼭 기억하십시오

- 하루에 **두세 개 질문**이면 충분합니다. 급할 것 없습니다.
- 클로드는 **말씀하신 것에 없는 이야기를 지어내지 않습니다.**
- 말씀 그대로도, 다듬은 글도 **모두 저장되어 사라지지 않습니다.**
- 아픈 이야기는 **언제든 건너뛰셔도 됩니다.**
