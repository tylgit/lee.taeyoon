## 자서전 만들기

어르신이 말 한마디로 자서전을 만들 수 있는 도구입니다.

- **"인터뷰 시작해 줘"** → 질문을 하나씩 여쭙습니다 (`interview` 스킬)
- **"책으로 만들어 줘"** → 워드·PDF·HTML 완성본을 만듭니다 (`book-build` 스킬)

자세한 안내는 [시작하기.md](시작하기.md) 를 보십시오.
학생별 폴더에 그대로 복사해 쓰실 수 있게 `자서전_시작폴더.zip` 으로도 들어 있습니다.

```
python3 tools.py status   # 답변 현황
python3 tools.py new      # 빈 답변지 만들기
python3 tools.py build    # 책으로 엮기
python3 tools.py zip      # 시작폴더 zip 다시 만들기
```
