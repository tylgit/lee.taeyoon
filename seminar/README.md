# 샬롬대학 시니어 AI 워크샵 · 2026-10-20 개정판

세미나 자료 3종. `assets/base.css`(공통 디자인 시스템)와 `parts/figs/*.html`(인라인 SVG 도표)를
`build.py`가 각 문서에 끼워 넣어 `dist/`에 자체 완결 HTML 한 장씩을 만든다.
아티팩트는 외부 요청이 전부 차단되므로 CSS·도표·스크립트를 모두 인라인한다.

| 산출물 | 무엇 | 쓰는 때 |
|---|---|---|
| `dist/textbook.html` | **교재** — 읽는 책. 12장 + 부록 3종 | 집에서 읽기 |
| `dist/slides.html` | **슬라이드** — 38장, 좌우 화살표로 넘김 | 강의 30분 |
| `dist/book2.html` | **교재 2권** — 2026-10-20 기준 신규 도구 비교 분석, 15장 | 집에서 읽기 |
| `dist/workbook.html` | **워크북** — 따라 하는 책, 실습 4개 | 실습 60분 |

실습 1~3은 하나의 프로젝트다: 5분 구술 → 자서전 원고 → 그 원고에서 뽑은 가사로 노래(Suno)
→ 그 노래와 옛 사진으로 영상(Clipchamp/iMovie). 실습 4는 비밀번호와 가족 안전 암호.

**참석자 사전 공지 필수** — **옛 사진 6~10장**을 가져와야 실습 3을 할 수 있다.
노트북이 없는 참석자를 위해 실습 3에는 구글 포토/아이폰 사진 앱으로 만드는 경로를 함께 적어 두었다.
