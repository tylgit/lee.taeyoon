# 🎵 YuE2 + Claude Code로 AI 노래 만들기 — 초보자용 따라하기 가이드

> 대상: **Windows PC + NVIDIA 그래픽카드**를 가진 완전 초보
> 목표: 내 PC에 YuE2를 설치하고 → 한국어 노래를 만들고 → 장르를 바꿔 편곡하기
> 원칙: **어려운 명령어는 Claude Code에게 맡기고, 나는 복사·붙여넣기와 확인만 한다.**

---

## 📋 전체 흐름 한눈에 보기

| 단계 | 할 일 | 누가 | 예상 시간 |
|---|---|---|---|
| 0 | 내 그래픽카드 확인 | 나 | 2분 |
| 1 | Claude Code 설치 | 나 | 10분 |
| 2 | ComfyUI 설치/업데이트 (0.36 이상) | 나 (+Claude 확인) | 15분 |
| 3 | YuE2 모델 다운로드 + 크기 검증 | **Claude** | 10~30분 (인터넷 속도) |
| 4 | ComfyUI에서 첫 노래 만들기 | 나 | 5분 |
| 5 | 가사 작성 + 여러 곡 한 번에 생성 | **Claude** | 5분 |
| 6 | 악보로 장르 바꿔 편곡 | **Claude** | 5분 |

> 💡 각 단계 끝에 **✅ 체크포인트**가 있습니다. 체크가 안 되면 다음 단계로 넘어가지 마세요.

## 0단계. 내 그래픽카드 확인하기 (2분)

1. 키보드에서 `Ctrl + Shift + Esc` → **작업 관리자** 열기
2. 위쪽(또는 왼쪽) **성능** 탭 클릭
3. 목록에서 **GPU** 클릭 → 오른쪽 위 이름과 **전용 GPU 메모리** 확인

| 내 전용 GPU 메모리 | 사용할 모델 |
|---|---|
| **16GB 이상** (예: RTX 4080, 5080, 4090, 5090) | 원본(BF16) 모델 |
| **8GB ~ 15GB** (예: RTX 3060 12GB, 4070) | 경량(INT8) 모델 |
| 8GB 미만 / NVIDIA가 아님 | ⚠️ 이 가이드로는 어렵습니다 |

✅ **체크포인트**: GPU 이름이 `NVIDIA GeForce RTX ...`로 나오고, 메모리 용량을 메모해 두었다.

## 1단계. Claude Code 설치하기 (10분)

> Claude Code는 **유료 요금제(Pro 이상)** 가 필요합니다. 하지만 노래 생성 자체는 0원입니다.

### 1-1. Git 설치 (Claude Code가 Windows에서 필요로 함)
1. 브라우저에서 `https://git-scm.com/download/win` 접속
2. 설치 파일 다운로드 → 실행 → **전부 "Next"** 눌러 기본값으로 설치

### 1-2. Claude Code 설치
1. 시작 버튼 → `PowerShell` 검색 → 실행
2. 아래 한 줄을 복사해서 붙여넣고 `Enter`
   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```
3. 설치가 끝나면 PowerShell 창을 **닫고 새로 연 다음** 입력:
   ```powershell
   claude
   ```
4. 브라우저가 열리면 Claude 계정으로 로그인

> 📌 설치 방법은 바뀔 수 있습니다. 안 되면 공식 문서 `https://code.claude.com/docs` 의 설치 안내를 따르세요.
> (Claude 데스크톱 앱이 있다면 앱의 **Code** 탭에서도 똑같이 쓸 수 있습니다.)

✅ **체크포인트**: PowerShell에서 `claude`를 입력하면 대화 화면이 뜬다.

### 🔑 Claude Code 사용 요령 (초보자 필수)
- Claude가 명령을 실행하기 전에 **"허용할까요?"** 라고 물어봅니다. 내용을 읽고 이해되면 허용, 모르겠으면 **"이게 뭐 하는 거야?"** 라고 물어보세요.
- 대화를 끝내려면 `/exit`, 다시 시작하려면 `claude`.

## 2단계. ComfyUI 준비하기 (15분)

YuE2는 **ComfyUI 0.36 버전부터** 기본 내장되어 있습니다. Windows에서는 이 방법이 가장 쉽습니다.

### 경우 A — ComfyUI를 처음 설치하는 경우
1. `https://www.comfy.org/download` 접속 → **Windows용 ComfyUI Desktop** 다운로드
2. 설치 파일 실행 → GPU 선택 화면에서 **NVIDIA** 선택
3. 설치 폴더는 기본값 그대로 두고 **설치 폴더 경로를 메모**해 두기

### 경우 B — 이미 ComfyUI를 쓰고 있는 경우
⚠️ 업데이트하면 기존에 쓰던 커스텀 노드/워크플로가 영향을 받을 수 있습니다.
**직접 업데이트하기 전에 먼저 Claude에게 확인을 받으세요.** (아래 지시서 ①이 이걸 해줍니다)

## 3단계. Claude에게 설치 지시서 전달하기 ⭐ 핵심

PowerShell에서 `claude` 실행 후, 아래 **지시서 ①** 을 통째로 복사해서 붙여넣으세요.
(`[ ]` 안은 내 상황에 맞게 고치세요.)

### 📜 지시서 ① — 설치 확인 & 모델 다운로드

```text
나는 초보자야. 내 Windows PC에 YuE2 음악 생성 모델을 ComfyUI로 쓰려고 해.
아래 순서대로 하나씩 진행하고, 각 단계가 끝날 때마다 쉬운 한국어로 결과를 알려줘.
명령을 실행하기 전에는 무엇을 하는 명령인지 한 줄로 설명해줘.

1. 그래픽카드 확인
   - nvidia-smi로 GPU 이름, 전체 메모리(VRAM), 드라이버 버전을 알려줘.
   - VRAM이 16GB 이상이면 BF16 원본, 그보다 작으면 INT8 경량 모델을 추천해줘.
   - 내 GPU 메모리: [예: 16GB]

2. ComfyUI 찾기 & 버전 확인
   - 내 PC에서 ComfyUI 설치 폴더를 찾아줘. (내가 아는 경로: [모르면 "모름"])
   - 설치된 ComfyUI 버전을 확인해서 0.36 이상인지 알려줘.
   - 0.36 미만이면 절대 직접 업데이트하지 말고, 업데이트 방법과
     업데이트 시 기존 커스텀 노드/워크플로에 생길 수 있는 영향을 먼저 설명한 뒤 멈춰줘.
     (업데이트는 내가 직접 할게.)

3. 모델 다운로드 (ComfyUI가 0.36 이상일 때만)
   - Hugging Face의 Comfy-Org/YuE2 저장소에서 필요한 파일을 받아줘.
     · YuE2 체크포인트 (BF16: yue2_3b_bf16.safetensors / INT8: yue2_3b_int8_convrot.safetensors)
       → ComfyUI/models/checkpoints/
     · 악보용 인코더 sheetsage2_bf16.safetensors → ComfyUI/models/audio_encoders/
   - 파일 이름이나 폴더가 저장소 README와 다르면 README를 따르고, 달라진 점을 알려줘.
   - 이미 같은 파일이 있으면 다시 받지 말고 4번 검증만 해줘.
   - 큰 파일이니 중간에 끊겨도 이어받기가 되는 방식으로 받아줘.

4. 다운로드 검증 (중요!)
   - 받은 각 파일의 크기를 Hugging Face에 올라온 원본 크기와 "바이트 단위"로 비교해줘.
   - 가능하면 SHA256 해시도 원본과 비교해줘.
   - 하나라도 다르면 "다운로드 실패"라고 알려주고 다시 받아줘.

5. 마무리 보고
   - 설치된 파일 목록, 크기, 검증 결과를 표로 정리해줘.
   - ComfyUI를 켜서 YuE2 템플릿을 여는 방법을 초보자용으로 알려줘.
```

### 이런 일이 일어납니다
- ComfyUI가 **0.35 이하**라면 → Claude가 "업데이트가 필요해요"라고 알려주고 멈춥니다.
  → ComfyUI Desktop: 앱 실행 시 뜨는 **업데이트** 버튼 클릭 (또는 메뉴의 업데이트 확인)
  → 업데이트 후 Claude에게 **"업데이트 했어. 3번부터 계속해줘"** 라고 입력
- 모델 다운로드는 수 GB라 시간이 걸립니다. **창을 닫지 말고 기다리세요.**
- 마지막에 **"바이트 크기 일치 ✅"** 가 나와야 성공입니다.
  (큰 파일은 중간에 끊겨도 다 받아진 것처럼 보일 수 있어서, 이 검증이 꼭 필요합니다.)

✅ **체크포인트**: Claude의 최종 보고 표에서 모든 파일이 "일치"로 나온다.

## 4단계. ComfyUI에서 첫 노래 직접 만들어보기 (5분)

1. ComfyUI 실행 (Desktop 앱 아이콘 더블클릭)
2. 왼쪽 메뉴에서 **템플릿(Templates)** 열기 → **Audio** 분류 → **YuE2** 선택
   (못 찾겠으면 Claude에게 "ComfyUI에서 YuE2 템플릿 여는 법 알려줘")
3. 모델 선택 칸이 방금 받은 파일(`yue2_3b_...`)로 되어 있는지 확인
4. **장르 설명(태그)** 칸에 입력 — **영어로, 맨 앞에 Korean**
   ```text
   Korean, ballad, female vocal, piano, strings, emotional, slow tempo
   ```
5. **가사** 칸에 입력 — **구간 표시([verse], [chorus])를 꼭 넣기**
   ```text
   [verse]
   창밖에 비가 내리던 저녁
   식어버린 커피잔을 들고
   오늘 하루도 참 길었다고
   작게 혼잣말을 해

   [chorus]
   괜찮아 괜찮아 다 지나갈 거야
   내일은 조금 더 웃을 수 있을 거야
   ```
6. 오른쪽 아래 **Run(실행)** 버튼 클릭 → 40~60초 기다리기
7. 결과 노드에서 ▶ 재생, 파일은 `ComfyUI/output` 폴더에 저장됩니다.

✅ **체크포인트**: 노래가 재생되고 output 폴더에 오디오 파일이 생겼다. 🎉

> 🔤 **장르 설명 쓰는 순서** (공식 권장): 언어 → 장르 → 보컬 → 악기 → 분위기 → 빠르기
> 영어가 어려우면 Claude에게 "시티팝으로 장르 설명 써줘"라고 하면 됩니다.

## 5단계. Claude에게 가사 작성 + 여러 곡 한 번에 생성 맡기기

한 곡씩 누르는 대신, Claude가 **가사 작성 → 여러 버전 자동 생성**까지 해줍니다.
**ComfyUI를 켜 둔 상태**에서 Claude Code에 아래를 붙여넣으세요.

### 📜 지시서 ② — 가사 작성 & 일괄 생성

```text
ComfyUI(YuE2)가 지금 실행 중이야. 아래대로 노래를 만들어줘.

[노래 정보]
- 주제: 금요일 밤 퇴근길 드라이브
- 장르: 시티팝
- 생성: 여자 보컬 2곡 + 남자 보컬 2곡 = 총 4곡

[할 일]
1. 주제에 맞는 한국어 가사를 새로 써줘.
   - [verse], [chorus], [bridge] 구간 표시를 넣고, 실제 가수의 가사는 절대 쓰지 마.
   - 먼저 가사를 보여주고 내 확인을 받은 다음 진행해줘.
2. 장르 설명은 영어로 "Korean, 장르, 보컬, 악기, 분위기, 빠르기" 순서로 써줘.
3. ComfyUI의 YuE2 워크플로를 API로 실행하는 파이썬 스크립트를 만들어서
   위 4곡을 순서대로 자동 생성해줘. (ComfyUI 주소: http://127.0.0.1:8188)
   - 워크플로 API 형식 파일이 필요하면 내가 ComfyUI에서 내보내는 방법을 알려줘.
   - 곡마다 seed를 다르게 해줘.
4. 결과 파일은 "output/날짜_주제" 폴더에 정리하고,
   곡마다 오디오 파일과 악보(ABC) 파일이 나란히 저장되게 해줘.
5. 끝나면 파일 목록과 각 곡 길이를 표로 알려줘.
```

> 📌 Claude가 "워크플로를 API 형식으로 내보내 달라"고 하면:
> ComfyUI 메뉴 → **Workflow → Export (API)** → 저장된 `.json` 파일 경로를 Claude에게 알려주면 됩니다.

### 듣고 고르기
- 같은 가사라도 **결과가 매번 다릅니다.** (어떤 곡은 중간에 간주가 들어가기도 함)
- 4곡을 다 들어보고 **가장 마음에 드는 곡 번호**를 메모하세요. 추가 비용은 0원!

✅ **체크포인트**: 4곡이 생성되었고, 마음에 드는 곡 하나를 골랐다.

## 6단계. 악보를 이용해 장르 바꿔 편곡하기

YuE2는 노래를 부르기 전에 **멜로디+코드 악보(ABC 형식)** 를 먼저 씁니다.
이 악보의 멜로디는 그대로 두고 장르만 바꾸면 **같은 노래의 다른 버전**이 나옵니다.

### 📜 지시서 ③ — 편곡 (트로트 / 보사노바)

```text
아까 만든 곡 중 [3번] 곡이 마음에 들어. 이 곡을 편곡하고 싶어.

1. 그 곡의 악보(ABC) 파일을 복사해서, 코드(화음) 표기만 지우고 멜로디는 그대로 남겨줘.
   원본 악보 파일은 건드리지 마.
2. 가사는 원곡과 똑같이 쓰고, 장르 설명만 바꿔서 다시 생성해줘.
   - 버전 A: 트로트 (Korean, trot, ...)
   - 버전 B: 보사노바 (Korean, bossa nova, ...)
3. 원곡과 편곡 버전들의 길이를 비교해서 표로 알려줘.
```

- 멜로디를 그대로 따라가므로 **원곡과 길이가 거의 같게** 나옵니다. (예: 2분 47초 → 2분 50초)
- 한 버전당 약 50~60초 걸립니다.

✅ **체크포인트**: 같은 멜로디의 트로트/보사노바 버전을 들어봤다. 🎶

| 오류 메시지가 이해 안 됨 | 오류 전체를 복사해서 붙여넣고 "초보자에게 설명하듯 알려주고 고쳐줘" |
