# 지식 노트 사용법

이 폴더는 이태윤의 지식 저장소입니다. 모든 노트는 옵시디언에서 열 수 있는 마크다운(.md) 파일입니다.

## 노트를 만드는 방법

1. 클로드(소울.엠디)에게: "오늘 ○○를 배웠는데 지식 노트로 정리해줘" → 이 폴더에 .md 파일로 저장됩니다.
2. 헤르메스 텔레그램 봇에게 배운 내용을 보내고 "지식 노트에 저장해줘" (헤르메스 연결 설정 후 가능)
3. 옵시디언에서 직접 작성 (제목은 "날짜 + 주제" 형식 권장)

## 노트 제목 규칙

- 예: `2026-08-04 크론잡이란 무엇인가.md`
- 날짜를 앞에 붙이면 시간 순으로 정렬되어 찾기 쉽습니다.

## 노트 내용 형식 (권장)

- 오늘 배운 것 (3줄 요약)
- 자세한 내용
- 나의 생각·질문
- 다음에 해볼 것
