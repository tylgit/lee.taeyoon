# 말로 만드는 자서전 — 사용 안내

90개 질문에 **말로 답하면**, 클로드가 받아 적고 다듬어 **완성본 책**으로 엮어 주는 도구입니다.

## 준비 (처음 한 번)

클로드코드(Claude Code)나 코워크(Cowork)에서 이 저장소를 열고 이렇게 말하세요:

> 인터뷰 시작해 줘

클로드가 답변 파일 90개를 만들고 첫 질문을 합니다.

## 매일 하는 것 — 인터뷰

1. "인터뷰 이어서 해 줘" 라고 말합니다.
2. 클로드가 질문을 하나 보여 줍니다.
3. **마이크 단추를 누르고 말로 답합니다.** (휴대폰·태블릿은 자판의 마이크, 컴퓨터는 받아쓰기 기능) 타이핑하셔도 됩니다.
4. 클로드가 말씀을 그대로 받아 적고, 자서전 문장으로 다듬어 보여 줍니다.
5. "좋다" 하시면 저장되고 다음 질문으로 넘어갑니다. 고치고 싶으면 "○○ 부분은 이렇게 고쳐 줘"라고 말하면 됩니다.

- 하루 두세 문이면 충분합니다. 한 달 반이면 90문이 끝납니다.
- "건너뛰어 줘", "기억이 안 나", "해당 없어" — 모두 됩니다.
- 언제든 "지금까지 얼마나 했어?" 라고 물으면 진행 상황을 보여 줍니다.

## 다 모이면 — 책 만들기

> 이제 책으로 만들어 줘

클로드가 ① 책 제목과 머리말을 함께 정하고, ② 답변들을 12개 장의 흐르는 이야기로 엮고, ③ 워드·PDF·HTML 완성본을 만들어 줍니다. 답을 다 못 채웠어도 "지금까지 것으로 만들어 줘"라고 하면 만들어 줍니다.

## 약속

- 클로드는 **말씀하신 내용에 없는 이야기를 지어내지 않습니다.**
- 말씀 원문은 `answers/` 폴더에 그대로 남습니다. 다듬은 글이 마음에 안 들면 언제든 원문으로 되돌릴 수 있습니다.
- 모든 기록은 이 저장소에 저장(커밋)되어 사라지지 않습니다.

## 직접 명령어를 쓰고 싶다면

```
python3 autobiography/tools.py status   # 진행 상황
python3 autobiography/tools.py next    # 다음 질문 보기
python3 autobiography/tools.py build   # 완성본 책 만들기
```
